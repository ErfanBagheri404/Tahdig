## 📖 درباره ته‌دیگ

**ته‌دیگ** یک اپلیکیشن اندرویدی است که بر اساس **ساعت روز**، غذای مناسب آن وعده را به‌صورت تصادفی پیشنهاد می‌دهد. دیگر نیازی نیست ساعت‌ها فکر کنید چه بپزید — ته‌دیگ این کار را برای شما انجام می‌دهد!

اپ کاملاً **آفلاین** است، **بدون حساب کاربری** است، و **هیچ داده‌ای جمع‌آوری نمی‌کند**.

## ✨ ویژگی‌ها

### 🕐 پیشنهاد هوشمند بر اساس ساعت
- **صبحانه** (۰۶:۰۰ – ۱۰:۳۰) · **ناهار** (۱۱:۳۰ – ۱۴:۳۰) · **شام** (۱۸:۳۰ – ۲۲:۰۰)
- **شام سبک** (۲۲:۰۰ – ۰۱:۰۰) · **میان‌وعده** (خارج از بازه‌ها)
- انتخاب خودکار وعده از ساعت سیستم

### 🎲 قرعه‌کشی مجدد
- دکمه «غذا دیگه» برای دریافت پیشنهاد جدید
- الگوریتم هوشمند: غذاهای اخیراً پیشنهادشده تکرار نمی‌شوند

### 🔍 جستجو و فیلتر
- جستجوی غذا بر اساس نام فارسی یا انگلیسی
- فیلتر بر اساس **۲۷ دسته** (خورش، کباب، پلو، سوپ، سالاد، ...)
- چیپ‌های دسته‌بندی برای دسترسی سریع

### ❤️ علاقه‌مندی‌ها و بلاک
- افزودن غذاهای مورد علاقه با یک ضربه
- بلاک کردن غذاهای ناخواسته (دیگر پیشنهاد نمی‌شود)
- لیست جداگانه علاقه‌مندی‌ها و مسدود شده‌ها

### 📜 تاریخچه پیشنهادها
- مشاهده تمام غذاهای پیشنهادشده با تاریخ و ساعت
- زمان‌بندی نسبی (اکنون، X دقیقه پیش، ...)
- قابلیت پاک‌سازی تاریخچه

### 📋 جزئیات غذا
- نمایش کامل نام فارسی و انگلیسی
- مواد لازم، زمان آماده‌سازی، سختی پخت
- برچسب‌ها (بدون گوشت، وگن، سنتی و ...)

### 🎨 هویت بصری دسته‌ها
- ایموجی اختصاصی برای هر دسته غذایی
- رنگ پس‌زمینه متناسب با دسته
- طراحی زیبا و خوانا

### ⚙️ تنظیمات و پوسته
- سه حالت پوسته: **سیستم** · **روشن** · **تاریک**
- ذخیره خودکار تنظیمات

### 🌍 فارسی و RTL
- کل رابط کاربری به زبان فارسی
- چیدمان راست به چپ اجباری
- فونت یکان‌بخ (۸ وزن)

## 📦 نصب

### از GitHub Releases
1. به [Releases](https://github.com/ErfanBagheri404/Tahdig/releases) بروید
2. نسخه متناسب با پردازنده خود را دانلود کنید:
   - **arm64-v8a** — اکثر گوشی‌های مدرن (پیشنهادی)
   - **armeabi-v7a** — گوشی‌های قدیمی‌تر
   - **universal** — همه پردازنده‌ها
3. فایل APK را نصب کنید (فعال‌سازی ناشناخته‌ها را روشن کنید)

### کامپایل از سورس
```bash
git clone https://github.com/ErfanBagheri404/Tahdig.git
cd Tahdig
./gradlew assembleDebug
```
