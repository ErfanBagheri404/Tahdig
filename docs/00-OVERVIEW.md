# ته‌دیگ (Tahdig) — نقشه راه

اپلیکیشن فارسی‌زبان پیشنهاد تصادفی غذا بر اساس ساعت روز.
اندروید فقط (Kotlin + Jetpack Compose). آفلاین، بدون حساب کاربری، بدون بک‌اند.

## اصول طراحی

1. **فارسی اول** — کل UI فارسی، RTL اجباری، فونت یکان‌بخ.
2. **آفلاین کامل** — دیتابیس لوکال، هیچ درخواست شبکه‌ای برای کارکرد اصلی.
3. **بدون حساب** — بدون لاگین، بدون ثبت‌نام، بدون جمع‌آوری داده.
4. **سادگی** — کاربر باید در ۲ ثانیه جواب بگیرد.
5. **دیتابیس مقیاس‌پذیر** — ۵۴۳ غذا الان، ساختار برای ۱۰۰۰+ آماده.

## ساعت‌های روز

| وعده | بازه | کلید |
|---|---|---|
| صبحانه | ۰۶:۰۰ – ۱۰:۳۰ | `BREAKFAST` |
| ناهار | ۱۱:۳۰ – ۱۴:۳۰ | `LUNCH` |
| عصرانه | ۱۵:۰۰ – ۱۷:۳۰ | `SNACK` |
| شام | ۱۸:۳۰ – ۲۲:۰۰ | `DINNER` |
| شام سبک | ۲۲:۰۰ – ۰۱:۰۰ | `LIGHT_DINNER` |
| میان‌وعده | خارج از بازه‌ها | `SNACK` |

منطق انتخاب: ساعت سیستم → کلید وعده → کوئری تصادفی از دیتابیس با فیلتر آن وعده.

## ساختار پروژه

```
Tahdig/
├── app/src/main/
│   ├── assets/seed/          ← دیتاست (۲۸ فایل JSON)
│   ├── java/.../tahdig/
│   │   ├── data/local/       ← Room DB, entities, DAOs, seed
│   │   ├── ui/theme/         ← Material 3, فونت، RTL
│   │   └── util/             ← نرمال‌سازی متن فارسی
│   └── res/font/             ← یکان‌بخ (۸ وزن)
├── docs/                     ← همین فایل‌ها
└── .github/workflows/        ← CI
```
